[Paradigm](https://paradigm.xyz/) is a technology investment firm led by Matt Huang and Alana Palmedo that builds and invests across AI, robotics, crypto, and other technical frontiers, from first check through public markets.

Founded in 2018, we combine deep technical research with hands-on building alongside the founders and teams shaping the frontier.

This Github Organization hosts all of Paradigm’s open source experiments, designs, and production-ready code.

Among other things, we are currently building:
* [Tempo](https://github.com/tempoxyz/tempo): The purpose-built blockchain for financial products. Incubated with Stripe.
* [Reth](https://github.com/paradigmxyz/reth): Modular, contributor-friendly and blazing-fast implementation of the Ethereum protocol, in Rust
* [Centaur](https://github.com/paradigmxyz/centaur): Centaur is frontier, agentic infrastructure that you own. Centaur is like Claude Tag, but open source and on steroids.
* [evmbench](https://paradigm.xyz/evmbench): an open benchmark from OpenAI and Paradigm that evaluates whether AI agents can detect, patch, and exploit high-severity vulnerabilities.
* [Iron Proxy](https://github.com/paradigmxyz/iron-proxy): An egress firewall for agentic untrusted workloads.
* [Foundry](https://github.com/foundry-rs/foundry/): A fast, portable and modular toolkit for Ethereum application development written in Rust.
* [Solar](https://github.com/paradigmxyz/solar/): A blazingly fast, modular and contributor friendly Solidity compiler, written in Rust.
* [Alloy](https://github.com/alloy-rs/): High-performance, well-tested & documented libraries for interacting with Ethereum and other EVM-based chains, in Rust.
* [RSI Simulator](https://www.paradigm.xyz/research/rsi/game): A web game that demonstrates the [economics of recursive self-improvement](https://elasticity.institute/rsi-paper.pdf) by allowing the user to control a simulated frontier AI lab.

We also support third party open source projects and organizations such as:
* [REVM](https://github.com/bluealloy/revm/): A blazing-fast hookable Rust EVM by [Dragan Rakita](https://github.com/rakita)
* [Wevm](http://github.com/wevm/): TypeScript tools for the frontier, by [Tom Meagher](https://github.com/tmm/) and [Jake Moxey](https://github.com/jxom)

You can learn more about our [research](https://www.paradigm.xyz/research) and [building](https://www.paradigm.xyz/build) at the Paradigm website.
